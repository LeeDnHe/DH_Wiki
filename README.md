# donghee-lee-wiki

이동희의 공개 LLM 위키. 사람과 AI가 함께 읽는 개인 지식 베이스.

## 구조

```
├── llms.txt                # LLM 진입점 (표준)
├── llms-full.txt           # 전체 덤프 (스크립트로 생성 예정)
├── index.md                # 사람용 홈
├── about.md                # 1페이지 요약
├── career/                 # 이력 & 스킬
├── projects/               # 프로젝트별 페이지
├── knowledge/              # 개발 노하우
└── _meta/                  # 위키 자체에 대한 문서
    ├── CLAUDE.md           # AI 편집 가이드
    └── style-guide.md      # 작성 규칙
```

## 배포
아직 미설정. 옵션:
- GitHub Pages
- Vercel
- Cloudflare Pages

## 편집
- 새 프로젝트/노하우 추가: `_meta/CLAUDE.md` 참고
- 스타일: `_meta/style-guide.md` 참고

## 비공개본
개인 일상 로그, 사고방식, 취향, 실패 기록 등은 별도 Notion 비공개 허브에 보관.
공개해도 될 내용만 선별해 이곳으로 승격(promote).
