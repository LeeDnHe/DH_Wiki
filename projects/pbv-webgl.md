# PBV WebGL Platform

## 개요
Unity UI Toolkit 기반 WebGL 전기차(PBV, Purpose Built Vehicle) 설계 플랫폼.

## 핵심 특징
- **브라우저 기반** — 별도 설치 없이 웹에서 전기차 커스터마이징
- **UI Toolkit 기반 디자인 시스템** — USS/UXML로 구성된 재사용 가능한 컴포넌트
- **Pretendard / NotoSansKR** 폰트 기반 한국어 UI

## 기술적 특이사항
- WebGL 환경에서의 UI Toolkit 제약 사항을 고려한 패턴
- Spacer 기반 간격 관리 시스템
- 커스텀 uGUI 드롭다운(DOTween 애니메이션, 9-Slice 스프라이트, WebGL 안전 입력 처리)

## 연관 스킬
- `unity-ui-toolkit-design` (개인 Claude Code 스킬)
