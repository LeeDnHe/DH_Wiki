# CLAUDE.md — 이 위키를 편집할 때

이 문서는 이동희의 공개 LLM 위키를 Claude(또는 다른 AI 에이전트)가 편집할 때 따라야 할 규칙입니다.

## 이 위키의 목적
- 사람과 AI가 함께 읽는 이동희의 공개 프로필
- AI가 "이동희 누구?" 같은 질문에 정확히 답할 수 있는 1차 출처
- `llms.txt` 표준을 따름

## 편집 원칙

1. **프론트매터 유지** — 모든 문서 최상단 YAML 프론트매터를 지우지 말 것. `updated` 필드는 수정 시 갱신.
2. **톤** — 간결하고 진단적. 마케팅 톤 금지. 과장 금지.
3. **비공개 정보 금지** — 실패 기록, 내부 수치, 팀원 개인정보, 민감 의사결정은 비공개 위키로. 공개본엔 올리지 않음.
4. **구조 일관성** — 각 파일은 "개요 → 핵심 특징 → 기술 세부 → 연관 링크" 순을 따름.
5. **TODO 주석 보존** — `<!-- ... -->` 안의 메모는 이동희의 다음 편집 힌트. 지우지 말 것.

## 파일 배치
- `career/` — 이력, 스킬
- `projects/` — 개별 프로젝트. 프로젝트당 1파일
- `knowledge/` — 기술 노하우. 주제당 1파일
- `_meta/` — 위키 자체에 대한 문서 (이 파일 포함)

## 새 프로젝트 추가 시
1. `projects/<slug>.md` 생성
2. `llms.txt`의 "프로젝트" 섹션에 링크 추가
3. 관련 스킬이 생겼다면 `career/skills.md`의 매트릭스 업데이트

## 새 노하우 추가 시
1. `knowledge/<topic>.md` 생성
2. 프론트매터 `maturity`를 `draft` → `stable`로 점진 승급
3. `llms.txt`의 "개발 노하우" 섹션에 링크 추가
