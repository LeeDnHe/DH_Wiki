# Style Guide

이 위키의 문서 작성 스타일 규칙.

## 프론트매터 (YAML)

모든 콘텐츠 문서는 최상단에 YAML 프론트매터를 둡니다.

필수:
- `title` — 문서 제목
- `updated` — YYYY-MM-DD

선택:
- `tags` — 주제 태그 배열
- `status` — 프로젝트의 경우 `active` / `paused` / `archived`
- `maturity` — 노하우 문서의 경우 `draft` / `stable`
- `summary` — 1~2줄 요약 (AI가 한 줄 소개할 때 쓰기 좋음)

## 문서 길이
- **프로젝트 페이지** — 한 화면에 다 보일 만큼 간결. 상세는 링크로.
- **노하우 페이지** — 개념 + 실전 교훈 중심. 튜토리얼 복사 지양.
- **about.md** — 1페이지 엄수.

## 헤딩 레벨
- `#` — 문서 제목 (파일당 1개)
- `##` — 주요 섹션
- `###` — 하위 섹션. 거의 쓰지 않는 게 좋음

## 링크
- 내부 링크는 절대 경로로: `/projects/xreal-two-of-us.md`
- 외부 링크는 신중히. 깨진 링크는 위키 전체 신뢰도를 떨어뜨림.

## 금지 표현
- "혁신적인", "세계 최초" 등 검증 안 되는 수식어
- 팀원 풀네임/개인정보 (이니셜 또는 역할로 지칭)
- 구체적 매출/수치 (공개 가능 확인 전까지)

## AI 친화적 글쓰기

- **능동태** 우선
- 한 문장 = 한 주장
- 전문 용어는 첫 등장에 간단한 괄호 설명
- **"나는"** 주어는 생략해도 됨. 이 위키는 이동희에 대한 것이므로 기본 주어가 정해져 있음.
